# AI速算

> 公考资料分析计算自动化训练 · 逐题计时 · 错题与慢题强化

## 主要功能

- **🎯 5种练习模式** — 智能训练 / 随机出题 / 基础巩固 / 拔高挑战 / 自选练习
- **📝 摸底测试** — 20题测出你的速算弱点，首次使用即可获得诊断画像
- **⏱️ 逐题计时** — 保存展示时间、提交时间、总耗时，并与每题目标时间比较
- **🔄 待强化训练** — 做错、做对但超时、同类表现不稳定，都会进入强化池
- **🧩 变式复习** — 优先生成同技能、同数字结构的新题，而不是只重复原题
- **📈 熟练度** — 按“技能 + 数字结构”显示未掌握、会做但慢、不稳定、已自动化
- **⏱️ 教练模式** — 40秒提示、60秒跳过、连错警告，模拟真实备考节奏
- **📊 本地数据** — 浏览器本地保存，支持 JSON 完整备份/恢复、CSV 学习记录和 Markdown 日报导出

## 特点

- **策略优先出题** — 每道题都有设计好的速算捷径（百化分、凑整、抵消、截位），不是随机数字堆砌
- **陷阱提示选项** — 错误选项可对应具体计算陷阱，作为辅助反馈
- **纯前端离线可用** — 零依赖，不需要后端，不需要网络，浏览器打开即用
- **移动端优化** — 手机练习体验优先

## 数据边界

- 不设固定训练天数或每日强制任务，用户自行决定何时开始和练多少。
- 不需要注册、登录或云端数据库。
- 浏览器清理数据或更换设备前，请先导出完整 JSON 备份。
- “智能训练”使用本地规则安排题目，不依赖大模型接口。
